# Digestives

A scroll-driven page that follows one digestive biscuit from the packet, through its anatomy and the flavour range, into a cup of tea and on to the last bite.

**View the site:** https://shrer488.github.io/Digestives/

## Files

- `index.html` – the whole page (markup, styles and script)
- `img/` – the biscuit photos the page loads

To view it locally, serve the folder (for example `python3 -m http.server`) and open `http://localhost:8000`.
